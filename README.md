# Quantity Measurement App

A Spring Boot application for performing and managing quantity measurement operations such as **compare, convert, add, subtract, and divide** across different units (Length, Weight, Volume, Temperature).  
The project demonstrates layered architecture with **Controller → Service → Repository → Database** flow.

---

## Features
- Compare two quantities
- Convert between units
- Perform arithmetic operations (add, subtract, divide)
- Track history of operations
- View error history and operation counts
- REST API endpoints with Swagger documentation
